# UI-тесты сервиса «Самокат»

Автотесты учебного сервиса заказа самокатов (Sprint 6).

## Что проверяется

- Раскрытие вопросов в блоке «Вопросы о важном» на главной странице (8 вопросов — текст ответа совпадает с ожидаемым)
- Переход на главную страницу по логотипу «Самоката»
- Открытие Дзена в новой вкладке по логотипу Яндекса
- Полный флоу оформления заказа: обе точки входа (кнопка в шапке и блок «Как это работает» внизу страницы), заполнение формы «Для кого самокат» и «Про аренду», подтверждение заказа

## Стек

- Python 3.11
- Selenium WebDriver (Firefox / Geckodriver)
- pytest
- allure-pytest — шаги и отчётность
- Page Object Model

## Запуск

Установить зависимости:

```
pip install -r requirements.txt
```

Запустить все тесты с сохранением результатов для отчёта:

```
pytest tests/ -v --alluredir=allure_results
```

Открыть Allure-отчёт:

```
allure serve allure_results
```

## Итог

Все 12 тестов проходят стабильно. Особенность проекта — выбор станции метро в React-селекте, где обычный клик по опции не всегда обрабатывается: обходим через клавиатурный выбор (ArrowDown + Enter) с проверкой фактического значения в поле.
