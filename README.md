# Sprint_6 — UI-тесты сервиса Samokat

Проект: автоматизация UI-тестов веб-приложения «Самокат» (Selenium + pytest + Allure).

## Стек

- **Python 3.11**
- **Selenium WebDriver** — управление браузером
- **pytest** — тестовый фреймворк, параметризация по браузерам
- **Allure** — отчёты о прохождении тестов (`allure-pytest`)

## Структура проекта

```
Sprint_6/
├── conftest.py            # фикстуры pytest: создание и закрытие драйвера, выбор браузера
├── data.py                # тестовые данные: BASE_URL, сценарии заказа, тексты вопросов FAQ
├── requirements.txt       # зависимости проекта
├── pages/                 # Page Object Model
│   ├── base_page.py       # базовый класс: работа с драйвером, ожидания, ретраи кликов
│   ├── main_page.py       # главная страница: кнопка «Заказать», куки-баннер
│   ├── order_page.py      # формы оформления заказа (два шага) и окно успеха
│   ├── faq_page.py        # аккордеон «Вопросы о важном»
│   └── track_page.py      # страница отслеживания заказа
└── tests/
    ├── test_faq.py        # проверка ответов в аккордеоне вопросов
    ├── test_logos.py      # переходы по логотипам «Самокат» и «Яндекс»
    └── test_order_flow.py # полный флоу оформления заказа (две точки входа, два пользователя)
```

## Запуск тестов

1. Установи зависимости:

```powershell
pip install -r requirements.txt
```

2. Запусти тесты с сохранением результатов для Allure:

```powershell
python -m pytest tests -v --alluredir=allure_results
```

Тесты параметризованы по браузерам (chrome / firefox). Результаты сохраняются в папку `allure_results` — отчёт Allure строится на их основе:

```powershell
allure serve allure_results
```

## Итог

Все 12 тестов проходят стабильно. Особенность проекта — выбор станции метро в React-селекте, где обычный клик по опции не всегда обрабатывается: обходим через клавиатурный выбор (ArrowDown + Enter) с проверкой фактического значения в поле.
